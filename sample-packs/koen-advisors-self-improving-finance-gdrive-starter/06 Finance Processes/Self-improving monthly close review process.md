# Self-improving monthly close review process

## Goal

Turn each monthly close into:

1. A CFO-ready close review memo.
2. A Quality Gate result.
3. Learning candidates for the next cycle.
4. CFO-approved learning that improves future close reviews.

## Review sequence

### Step 1: Read prior approved learning

Before reviewing the current month, read:

- Prior Quality Gate and Learning Notes.
- Prior approved learning in Notion, if connected.
- Prior month close memo, if available.

Apply approved learning only. Do not treat unapproved learning candidates as operating memory.

### Step 2: Read the current close evidence

Read the controller notes first, then the P&L, GL activity, bank activity, AR aging, inventory valuation, and debt schedule.

### Step 3: Produce the CFO close summary

Answer:

1. What happened?
2. Why did it happen?
3. What is confirmed?
4. What is still uncertain?
5. What decisions or follow-ups are required?
6. What should management know?

### Step 4: Run the Quality Gate

Evaluate the close summary against:

1. Source grounding
2. Finance logic
3. Materiality
4. Continuity with prior approved learning
5. Open issues and uncertainty
6. Learning candidates for the next cycle

### Step 5: Ask for CFO approval

Learning candidates are proposals only.

Ask the CFO to approve, edit, or reject each learning candidate.

### Step 6: Promote approved learning

Only after explicit CFO approval, write approved learning to Notion or the approved memory layer.

## Important rule

The goal is not just to make the next close memo better. The goal is to make the finance system better at producing the next close memo.
